## 2026-02-16 - [Character Counter for Prompt Inputs]
**Learning:** Character counters provide immediate feedback and help users understand input constraints, especially in AI-driven generation flows where prompt length matters. Using a subtle absolute-positioned overlay with `pointer-events-none` and a semi-transparent background (`bg-background/80`) keeps the counter visible without cluttering the layout or interfering with interactions.
**Action:** Implement character counters for all major prompt/instruction inputs using this pattern.
