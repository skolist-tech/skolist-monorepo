## 2025-05-15 - Prompt Input Polish
**Learning:** Adding a character counter and clear button to the primary AI generation prompt significantly improves user confidence and control. The `pr-10` padding is essential when adding absolute-positioned elements inside textareas to prevent text overlap.
**Action:** Always include character feedback and a reset mechanism for multi-line inputs that drive AI generation.

## 2025-05-15 - Interactive Card Feedback
**Learning:** A subtle `hover:-translate-y-1` effect combined with a slightly longer `duration-300` transition makes question cards feel more tangible and interactive, providing immediate visual confirmation of the focus state.
**Action:** Apply consistent lift effects to interactive cards throughout the Skolist apps.
