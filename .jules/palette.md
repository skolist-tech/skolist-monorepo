## 2025-05-15 - [PromptBox UX Enhancement]
**Learning:** Adding a "Clear" button and a character counter significantly improves the perceived quality of text inputs. Using shared components like @skolist/ui Textarea ensures a consistent look and feel while reducing custom CSS.
**Action:** Always check if text inputs can benefit from a character counter (especially if there's a limit or it's for AI prompts) and a quick clear action.
